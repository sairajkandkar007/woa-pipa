# Device Overview — Xiaomi Pad 6 (pipa)

## Known starting points

- Device: Xiaomi Pad 6
- Codename: pipa
- Platform: Qualcomm Snapdragon 870
- GPU: Adreno 650
- Intended OS architecture: Windows on ARM64

These details identify the research target; they do not establish that Windows boots or that hardware is supported.

## Research questions

- Which boot firmware and partition layout are present on the exact device variant?
- What device-tree, kernel, and vendor sources are available?
- Which peripherals depend on proprietary firmware or undocumented interfaces?
- What is required for UEFI, ACPI, storage, display, input, networking, audio, and power management?
- Which findings are confirmed from source code and which require device testing?

## Source hygiene

Record the source URL, branch or revision, date accessed, and what the source actually establishes. Avoid treating a related Qualcomm device as proof of pipa compatibility.
