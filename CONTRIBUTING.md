# Contributing

Contributions are welcome, including documentation, source research, test reports, and technical review.

## Useful contributions
- Reliable hardware and boot-chain documentation.
- UEFI, EDK II, ACPI, Qualcomm, ARM64, and Windows driver research.
- Reproducible test reports with logs and clear limitations.
- Corrections to documentation and links to primary sources.

## Before opening an issue
1. Search existing issues and documentation.
2. State whether the information is confirmed, inferred, or still a hypothesis.
3. Include source links and dates for research claims.
4. Remove passwords, tokens, private keys, serial numbers, and other personal information from logs.

## Bug or test report
Include:
- Device and codename
- Firmware / OS / build identifier, when applicable
- Component being tested
- Exact steps to reproduce
- Expected and observed result
- Relevant logs or screenshots
- What has already been tried

## Pull requests
- Keep changes focused and explain why they are needed.
- Prefer primary sources and reproducible evidence.
- Do not commit proprietary files unless redistribution is explicitly permitted.
- Do not include secrets, credentials, or personal data.
- Do not describe a feature as working without evidence from the actual device.

All contributions should respect applicable licenses and the rights of original authors.
